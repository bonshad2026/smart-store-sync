# راهنمای تحویل پروژه — فروشگاه‌یار هوشمند

آخرین به‌روزرسانی: ۷ آبان ۱۴۰۵ (۲۹ اکتبر ۲۰۲۶)
جزئیات فنی برای توسعه‌دهنده در فایل `CLAUDE.md` در ریشهٔ پروژه است.

## وضعیت فعلی
همهٔ کارهای زیر در برنچ `main` هستند و CI روی آن‌ها سبز است.

### ۱) ورود و حساب کاربری
- ثبت‌نام، ورود، خروج. اولین حساب، مدیر فروشگاه می‌شود.
- تأیید ایمیل، فراموشی رمز، تغییر رمز و ویرایش پروفایل.
- دیدن و قطع نشست‌های فعال روی دستگاه‌های دیگر (صفحهٔ «حساب کاربری»).
- ایمیل‌ها واقعاً ارسال می‌شوند (SMTP جیمیل در `.env`).

### ۲) تلگرام
- ربات اصلی سیستم: `@SmartStoreSyncBot`. در BotFather گزینهٔ Bot Management Mode برایش روشن است.
- هر فروشگاه از داخل پنل ربات اختصاصی خودش را می‌سازد و فقط در تلگرام تأیید می‌کند.
- اتصال کانال: «کانال‌های انتشار ← تلگرام ← اتصال کانال». QR را با گوشی اسکن کنید، Start بزنید و کانال را انتخاب کنید.
- از پنل: انتشار پست در کانال، دیدن تعداد اعضا، ورود و خروج اعضا، پست‌ها، ری‌اکشن‌ها و کلیک دکمه‌ها، و قطع یا اتصال دوبارهٔ کانال.
- تلگرام تعداد بازدید و فوروارد پست‌ها را به ربات‌ها نمی‌دهد، برای همین این دو آمار نمایش داده نمی‌شوند.

### ۳) تست و کنترل کیفیت
- ۷۲ تست خودکار برای بخش ورود و تلگرام وجود دارد.
- روی هر Pull Request، GitHub Actions خودکار تست و build را اجرا می‌کند. فقط وقتی سبز شد merge کنید.

## اجرای پروژه روی سیستم توسعه
۱. `docker compose up -d postgres`
۲. در پوشهٔ `backend`: `npm run dev` (پورت ۴۰۰۰)
۳. در پوشهٔ `frontend`: `npm run dev` و بعد آدرس `http://localhost:5173`

## تنظیمات مهم `.env`
- `TELEGRAM_BOT_TOKEN`: توکن ربات اصلی.
- `APP_SECRET`: کلید رمزنگاری توکن ربات‌های فروشگاه‌ها. **بعد از ساخت ربات‌ها هرگز عوضش نکنید**، وگرنه ربات‌ها از کار می‌افتند.
- `SMTP_*`: برای ارسال ایمیل.
- `APP_URL`: آدرس داشبورد، برای لینک‌های داخل ایمیل.

## روند کار با گیت
برنچ جدید از `main` ← کار و تست ← Pull Request ← CI سبز ← merge.

## قدم بعدی
اتصال واقعی **اینستاگرام**: انتشار و دیدن تعاملات، با کمترین کار برای صاحب فروشگاه. فعلاً اینستاگرام فقط متن آماده برای کپی تولید می‌کند.
